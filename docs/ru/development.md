# Разработка

```bash
dotnet build Awg-easy.sln
dotnet test Awg-easy.sln

cd frontend
pnpm install
pnpm run dev        # против локально запущенной панели
pnpm run lint
pnpm run typecheck
pnpm run test       # vitest в окружении Nuxt
cd ..

# Агент компилируется заранее (AOT), и анализатор trim/AOT работает только здесь — успешный
# `dotnet build` ничего не говорит о том, собирается ли агент до конца.
dotnet publish src/AwgEasy.Node -c Release -r linux-x64
```

`.github/workflows/ci.yml` гоняет всё это на каждый pull request и на каждый push в `main` и падает на любой
известной уязвимости в графе зависимостей. Образы там не собираются: они тянут Go-тулчейн и
исходники AmneziaWG — минуты и гигабайты ради того, что меняется гораздо реже кода.

## Прогон всей связки

```bash
sh scripts/e2e.sh     # нужны docker, curl, jq и /dev/net/tun
```

Поднимает панель, две ноды и пробу в контейнерах на одной машине и гоняет их через админское
API. Он покрывает то, до чего тестам не достать: агент применяет бандл через awg-quick и
amneziawg-go, проба делает настоящий хендшейк с каждой нодой и тянет страницу через туннель, и
воспроизводятся оба вида блокировки — когда хендшейк не проходит вовсе и когда он проходит, а
трафика за ним нет. Он собирает оба образа, поэтому живёт в отдельном workflow
(`.github/workflows/e2e.yml`): по ночам, по кнопке и на pull request, который задевает образы,
агента или контракт.

Какой проект за что отвечает — в [таблице раскладки](../../README.md#layout).

## Разбор бандла без панели

Удобно при отладке ноды:

```bash
awg-node --render-bundle bundle.json --control-key <base64url> --egress ens3
```

Он прогонит проверки приёмки и напечатает конфиг интерфейса, который применил бы, ничего при этом
не трогая. Оба флага необязательны: `--egress` по умолчанию `eth0`, а без `--control-key` подпись
**не проверяется** — об этом будет сказано в stderr, и payload отрендерится как есть. Для чтения
бандла этого достаточно, для доверия к нему — нет.

Архитектурные инварианты, которые стоит знать перед правкой кода, собраны в [AGENTS.md](../../AGENTS.md).
