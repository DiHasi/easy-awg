# Справочник настроек

## Панель

| Переменная | Назначение |
| --- | --- |
| `AWG_ENDPOINT_HOST` | Что клиенты видят как endpoint. **Это и есть точка переключения.** |
| `AWG_PORT` | UDP-порт для подключения клиентов. По умолчанию 51820. |
| `AWG_SUBNET` | Подсеть туннеля; адреса выделяются из неё на весь флот. По умолчанию `10.8.0.0/24`. |
| `AWG_CLIENT_ALLOWED_IPS` | Значение `AllowedIPs` в клиентских конфигах. По умолчанию `0.0.0.0/0, ::/0`. |
| `AWG_CLIENT_DNS` | DNS-серверы в клиентских конфигах. |
| `AWG_ADMIN_USER`, `AWG_ADMIN_PASSWORD` | Создание первого администратора на пустой базе. |
| `AWG_CONTROL_DB` | Файл SQLite. По умолчанию `/etc/awg-control/control.db`. |
| `AWG_BUNDLE_LIFETIME_MINUTES` | Срок жизни подписанного бандла. По умолчанию 15. |
| `AWG_USAGE_RETENTION_DAYS` | Сколько дней хранится почасовая история трафика по пирам для страницы Traffic. `0` — не вести её вовсе. По умолчанию 90, максимум 365. |
| `AWG_AVAILABILITY_RETENTION_DAYS` | Сколько дней хранится история доступности: как стояла каждая нода и что о ней видела каждая проба. `0` — не вести её вовсе. По умолчанию 90, максимум 365. |
| `AWG_METRICS_TOKEN` | Включает `/api/metrics` и служит bearer-токеном для него. Без значения эндпоинт выключен. |
| `AWG_IMPORT_LEGACY_STATE` | Разовое усыновление старого `state.json`. |
| `AWG_CLOUDFLARE_API_TOKEN` | Позволяет панели менять запись сама. Нужны права `Zone:Read` и `Zone:DNS:Edit`. |
| `AWG_CLOUDFLARE_ZONE_ID` | Зона, в которой живёт запись. Без обоих значений переключение остаётся ручным. |
| `AWG_DNS_RECORD_NAME` | Какую запись переводить. По умолчанию `AWG_ENDPOINT_HOST`. |
| `AWG_DNS_TTL` | TTL записи, он же ограничение скорости фейловера. По умолчанию 60. |
| `AWG_FAILOVER_CHECK_SECONDS` | Как часто панель оценивает флот. По умолчанию 30. |
| `AWG_FAILOVER_GRACE_SECONDS` | Сколько активная нода должна быть недоступна, прежде чем трафик уйдёт. По умолчанию 120. |
| `AWG_FAILOVER_COOLDOWN_MINUTES` | Минимальная пауза после любого переключения до автоматического. По умолчанию 15. |
| `AWG_NODE_STALE_SECONDS` | Нода без отчёта дольше этого считается silent. По умолчанию 90. |
| `AWG_PROBE_STALE_SECONDS` | Результаты проб старше этого игнорируются. По умолчанию 300. |
| `AWG_PROBE_INTERVAL_SECONDS` | Как часто пробы делают обход. По умолчанию 60. |
| `AWG_PROBE_HANDSHAKE_TIMEOUT_SECONDS` | Сколько проба ждёт хендшейк одной ноды. По умолчанию 15. |
| `AWG_PROBE_CHECK_URLS` | Что пробы открывают через туннель, через запятую; засчитывается любой ответ. По умолчанию `http://1.1.1.1/cdn-cgi/trace`, `http://connectivitycheck.gstatic.com/generate_204`. `none` — проверять только хендшейк. |
| `AWG_PROBE_TRAFFIC_TIMEOUT_SECONDS` | Сколько ждать ответа от каждого из них. По умолчанию 8. |
| `AWG_PANEL_ROLE` | `active` или `standby`, и только на пустой базе: текущая роль хранится, поэтому повышение переживает перезапуск. По умолчанию `active`. |
| `AWG_PANEL_URL` | Базовый URL этой панели в том виде, в каком до неё дотягивается вторая. Нужен, чтобы подключить резервную, и нужен на ней самой — без него смещённой панели никто не сможет об этом сообщить. |
| `AWG_PANEL_PUBLIC_IP` | Куда переводится запись панели, когда эта панель забирает флот. |
| `AWG_PANEL_NAME` | Как эта панель называется в паре. По умолчанию имя машины. |
| `AWG_PANEL_PEER_URL` | На резервной: куда подключаться. Дальше URL второй панели приходит с каждым снапшотом. |
| `AWG_PANEL_ENROLLMENT_TOKEN` | Одноразовый токен из Nodes -> Panel pair. Тратится при первом использовании. |
| `AWG_PANEL_DNS_RECORD_NAME` | Запись, за которой агенты идут к панели; переводится при повышении. Без неё перевод остаётся на вас, а ноды тем временем остаются fail-static. |
| `AWG_PANEL_SYNC_SECONDS` | Как часто резервная тянет состояние. По умолчанию 30. |
| `AWG_PANEL_FAILOVER_GRACE_SECONDS` | Сколько резервная должна не тянуть, прежде чем ей будет можно забрать флот. Должно быть больше `AWG_PANEL_SYNC_SECONDS`. По умолчанию 300. |
| `AWG_PANEL_FAILOVER_COOLDOWN_MINUTES` | Минимальная пауза между сменами роли здесь. По умолчанию 15. |
| `AWG_PANEL_WITNESS_URLS` | Что резервная открывает, чтобы проверить свой канал, через запятую; засчитывается любой ответ. Единственный свидетель, который есть у панели, поэтому `none` запрещает автоматику, а не разрешает её наугад. По умолчанию — те же URL, что у проб. |
| `AWG_PANEL_WITNESS_TIMEOUT_SECONDS` | Сколько ждать ответа от каждого. По умолчанию 8. |
| `AWG_PANEL_STREAM_BATCH` | Сколько строк истории за один запрос, пока резервная догоняет. По умолчанию 5000. |
| `AWG_NOTIFY_WEBHOOK_URL` | Куда отправлять уведомления JSON-запросом POST. |
| `AWG_NOTIFY_TELEGRAM_BOT_TOKEN`, `AWG_NOTIFY_TELEGRAM_CHAT_ID` | Бот и чат Telegram для уведомлений. |

## Нода

| Переменная | Назначение |
| --- | --- |
| `AWG_CONTROL_URL` | Адрес панели. |
| `AWG_ENROLLMENT_TOKEN` | Нужен только для первого запуска. |
| `AWG_EGRESS_INTERFACE` | Оставьте пустым — интерфейс определится по default route. |
| `AWG_HEALTH_URL` | Health-эндпоинт агента. Биндится на хосте. По умолчанию `http://127.0.0.1:8081`. |
| `AWG_POLL_INTERVAL_SECONDS` | Частота опроса новой ревизии. По умолчанию 20. |
| `AWG_NODE_STATE_PATH` | Идентичность агента и кэш бандла. По умолчанию `/etc/awg-node`. |
| `AWG_INTERFACE` | Имя интерфейса. По умолчанию `awg0`. Проба его игнорирует и использует `awgprobe`. |
| `AWG_INTERFACE_CONFIG_PATH` | Куда пишется сгенерированный конфиг awg-quick. По умолчанию `/etc/amnezia/amneziawg/awg0.conf`. |
| `AWG_BUNDLE_FILE` | Локальный бандл, который применяется вместо запроса к панели: для бутстрапа и проверки ноды без панели. Для пробы игнорируется. |
| `AWG_PUBLIC_IP` | Задать внешний адрес ноды вручную вместо автоопределения. |
| `AWG_PUBLIC_IP_URLS` | Эхо-сервисы для автоопределения. Пустое значение выключает его. |
| `AWG_PUBLIC_IP_REFRESH_MINUTES` | Как часто перепроверять известный адрес. По умолчанию 10. |
| `AWG_ROLE` | `probe` запускает образ как пробу вместо ноды. Её состояние лежит в `/etc/awg-probe`. |

Обфускация настраивается **не** переменными окружения. Она общая для флота и задаётся в панели в
разделе **Fleet**, поэтому изменение применяется сразу ко всем нодам.
